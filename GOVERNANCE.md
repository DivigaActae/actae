# Governance

Actae is maintained by Diviga. Decisions are made by the maintainer.

- Roadmap: public, in the pinned roadmap issue.
- Breaking changes: announced in CHANGELOG.md at least one minor version ahead.
- Contributions: accepted by invitation; see CONTRIBUTING.md.
- The managed service is operated by Diviga and is not governed by this file.

If the project grows beyond one maintainer, this file will be replaced with a
reviewer/committer model.
